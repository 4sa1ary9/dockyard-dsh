# App icon source

`AppIcon.icns` is generated from the DeepSeek website's official favicon:

<https://www.deepseek.com/favicon.ico>

The logo is recolored white and placed on a solid black background for the Dockyard DSH application icon at the user's request. `deepseek-logo-black-white.png` is the preview source, and `AppIcon.icns` is generated from the iconset.
